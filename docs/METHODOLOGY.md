# المنهجية

## مبدأ عدم الدمج

`Bankak-SDG` و`Cash-SDG` و`MTN-MoMo-RWF` و`Bank-RWF` مسارات مختلفة في السيولة والمخاطر والتسوية.
المؤشر يعرض سعر كل مسار على حدة، مع مؤشر مرجعي جامع **واضح المنهجية** عبر مسار USDT/USDC وليس عبر متوسط مضلل.

## أولوية المصادر

1. صفقات P2P مكتملة مثبتة
2. أسعار RFQ ملزمة
3. إعلانات Binance P2P العامة
4. بيانات بنكية رسمية (لاكتشاف الشذوذ فقط)
5. مصادر السوق الموازي الموثوقة
6. بذور معايرة مؤرخة (ليست سعرًا حيًا)

## التجميع

- Weighted Median
- سقف 10% لأي تاجر من وزن المؤشر
- استبعاد الشواذ عبر MAD
- استبعاد ضعف الإكمال/التقييم
- فصل حسب المبلغ / المدينة / طريقة الدفع
- لا تحريك للسعر بمرور الزمن وحده؛ التحريك عند معلومة سوقية جديدة

## معادلة SDG→RWF

`ExecutableRate = ExecutableBid_RWF_USDT ÷ ExecutableAsk_SDG_USDT`

حيث السعر = وحدات نقدية محلية لكل 1 USDT، والتنفيذ عبر VWAP لعمق يكفي المبلغ.

## الربح

```
GrossMargin = SellPrice - BuyPrice
```

صافي الربح يُعرض فقط عند توفر بنود التكلفة؛ وإلا يُوسم الإجمالي كـ«تقدير».
