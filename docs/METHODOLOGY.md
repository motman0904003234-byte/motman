# المنهجية

## مبدأ الفصل

كل مسار سعر مستقل: Bankak-SDG، Cash-SDG، MTN-MoMo-RWF، Bank-RWF. المؤشر الجامع يوضّح المنهجية ولا يدمج المسارات في رقم مضلل.

## ترتيب مصادر الوزن

1. صفقات P2P مكتملة مثبتة (وزن 1.0)
2. أسعار RFQ ملزمة (0.7)
3. إعلانات Binance P2P (0.35)
4. سوق موازٍ موثوق (0.25)
5. مراجع رسمية — لكشف الأخطاء فقط (0.15)
6. عينات معايرة / اصطناعية — وزن 0 في المؤشر الحي

## التنقية

- Weighted Median بدل المتوسط
- سقف 10% لوزن أي تاجر
- استبعاد غير القابل للمبلغ، الشاذ (MAD)، التقييم/الإكمال المنخفض
- إزالة تكرار الإعلانات وفصل الحسابات المرتبطة
- الفصل حسب المبلغ، المدينة، طريقة الدفع
- لا يتغير السعر بمرور الوقت وحده — فقط بمعلومة سوقية جديدة
- البيانات الأقدم من حد المصدر → `STALE`

## التنفيذ عبر USDT

للمبلغ وطريقة الدفع والاتجاه المحددين:

```
ExecutableRate = ExecutableBid_RWF_USDT ÷ ExecutableAsk_SDG_USDT
```

VWAP عبر عمق العروض حتى امتلاء الكمية. إن لم يمتلئ العمق → لا سعر تنفيذي.

## التقدير عند السيولة الأحادية

```
EstimatedRate = ShadowRate × (1 - DynamicDealerMargin)
```

التسمية الإلزامية في الواجهة: **سعر تقديري غير قابل للتنفيذ**.

## ربح التاجر

```
GrossMargin = SellPrice - BuyPrice
```

صافي الربح فقط إذا توفرت كل التكاليف (Binance، بنكك، MoMo، سيولة، صرف نقدي، مخاطر مخزون، نزاعات). وإلا يُعرض الإجمالي مع وسم **تقديرًا**.

## الدقة

```
PercentageError = abs(PredictedPrice - ActualCompletedPrice) / ActualCompletedPrice × 100
```

لا تُستخدم كلمة Accuracy بلا هذا التعريف. لا إثبات دقة ببيانات وهمية.
