# الأمن والامتثال — المرحلة 1

## ما نفعله

- بيانات أسعار وتنبيهات فقط
- تشفير معرف التاجر (SHA-256 مع ملح محلي)
- سجل تدقيق لكل اقتباس ورفع
- موصل صفقات يعمل محلياً؛ السرّ لا يُرفع

## ما لا نفعله

- لا حفظ أموال عملاء
- لا تنفيذ صرف تلقائي
- لا جمع بيانات بنكك السرية / PIN / OTP / هاتف / اسم حقيقي / رقم حساب
- لا صلاحية سحب أو أوامر على Binance — قراءة تاريخ C2C فقط

## الحقول المسموح رفعها من الموصل

وقت الصفقة، العملة، الاتجاه، الكمية، السعر، الإجمالي، طريقة الدفع، الرسوم، حالة COMPLETED، معرف تاجر مجهول مشفّر.

## قبل مطابقة التجار أو المدفوعات

مراجعة خصوصية + ترخيص + AML/KYC إلزامية. خارج نطاق المرحلة 1.
