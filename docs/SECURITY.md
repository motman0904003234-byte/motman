# الأمن والقانون

## حدود المرحلة الأولى

- بيانات وتنبيهات فقط
- لا حفظ أموال
- لا مطابقة تلقائية للتجار
- لا تنفيذ مدفوعات

## موصل التاجر المحلي

- يعمل على جهاز التاجر
- يستخدم مفتاح Binance محليًا للتوقيع فقط
- يرسل للحساب السحابي حقولًا مكتملة ومجهولة فقط
- الممنوع: الاسم، رقم الحساب، الهاتف، كلمة المرور، PIN، OTP، صلاحية السحب

## التدقيق

كل عملية `refresh` / `quote` / `rfq` / `completed_ingest` تُسجل في `/api/v1/audit`.

## قبل المرحلة التالية

راجع متطلبات الخصوصية والترخيص وAML/KYC في السودان ورواندا وأي سوق مستهدف قبل إضافة مطابقة التجار أو التنفيذ.
