# الأمن والامتثال — المرحلة 1

## النطاق المسموح

- بيانات أسعار وتنبيهات فقط.
- لا وصاية على أموال.
- لا تنفيذ صرف آلي.
- لا مطابقة تجار مدفوعة تؤثر على وزن المؤشر.

## موصل Binance المحلي

- يعمل على جهاز التاجر.
- صلاحية قراءة فقط لتاريخ C2C.
- المفتاح السري لا يغادر الجهاز.
- يُرفع فقط سجل مجهول مشفّر الهوية (`traderAnonId = SHA256(salt:apiKey)` محلياً).

## التشفير وسجل التدقيق

- ملفات الأسرار المحلية mode 600 تحت `.secrets/`.
- كل رفع تسعير/صفقات يُسجَّل في `data/local/audit.json`.

## الخصوصية وAML/KYC

قبل إضافة مطابقة تجار أو مدفوعات:

1. مراجعة متطلبات الترخيص في الولايات المعنية.
2. سياسة خصوصية وجمع أدنى للبيانات.
3. إجراءات KYC/AML إن لزم للتنفيذ المالي (خارج المرحلة 1).

## نموذج العمل (حوكمة المؤشر)

مجاني للأساسيات؛ احترافي للتنبيهات/التحليل؛ API مدفوع؛ تاريخ وتقارير؛ لوحة تجار؛ Widget.

**ممنوع:** الدفع مقابل ترتيب الأسعار أو وزن المؤشر.
