# تقرير الدقة والمخاطر ومصادر البيانات

## تعريف الخطأ

```
PercentageError = abs(PredictedPrice - ActualCompletedPrice) / ActualCompletedPrice × 100
```

## معايير القبول المستهدفة

| المعيار | الهدف |
|---------|--------|
| نسبة الأخطاء < 10% | ≥ 90% من العينات |
| MAPE | < 2% |
| Median Error | < 1.5% |
| P95 Error | < 5% |
| حجم العينة | ≥ 300 صفقة مكتملة حقيقية |
| تجار مستقلون | ≥ 10 |
| تقسيم زمني | ممنوع استخدام المستقبل في الماضي |

## الوضع الحالي في هذا المستودع

| البند | الحالة |
|------|--------|
| محرك التسعير والاختبارات البرمجية | مُنفَّذ |
| بيانات اصطناعية موسومة `isSynthetic` | متوفرة لاختبار البرمجيات فقط |
| صفقات Binance C2C الحقيقية | **غير متاحة في هذه البيئة** |
| إثبات دقة حية (MAPE/Median/P95) | **غير مُعلن — لا تُدعى الدقة** |
| موصل الاستيراد المحلي | جاهز (`apps/trader-connector`) |

لتفعيل تقييم الدقة الحقيقي بأمان:

1. أنشئ مفتاح Binance **قراءة فقط** بدون سحب/تداول.
2. على جهاز التاجر: `npx tsx apps/trader-connector/src/index.ts init --key ... --secret ...`
3. `sync` أو `import-file` لرفع الحقول المسموحة فقط.
4. كرّر على ≥10 تجار مستقلين و≥300 صفقة عبر فئات المبالغ والاتجاهات.
5. شغّل `/v1/accuracy/evaluate` مع عينات `isSynthetic:false` و`usedFutureData:false`.

## مصادر البيانات وأولويتها

1. صفقات P2P مكتملة مثبتة (موصل محلي)
2. RFQ ملزم
3. إعلانات Binance P2P (Bankak/MTN/USDT/USDC)
4. بنك الخرطوم / بنك السودان (رسمي — شذوذ فقط)
5. البنك الوطني الرواندي والبنوك الرواندية (رسمي — شذوذ فقط)
6. مصادر السوق الموازي الموثوقة
7. الأسعار الرسمية لا تُفرض كسعر تنفيذي

كل مصدر له Adapter مستقل؛ فشل واجهة غير رسمية ليس نقطة فشل وحيدة.

## المخاطر

- سيولة أحادية (شراء بدون بيع قابل للمبلغ) → تقديري أو «لا يوجد سعر تنفيذي».
- تلاعب/تداول ذاتي/كميات وهمية → كشف أولي + سقف وزن 10%.
- تأخر المصادر → DELAYED/STALE دون اختراع سعر.
- نقص بيانات التكاليف → هامش إجمالي فقط بعنوان «تقدير».
